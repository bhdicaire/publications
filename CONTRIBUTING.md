# Contributing Guidelines

Thanks for your interest in contributing!  

✅ You can:  
- Suggest improvements to existing mindmaps or diagrams  
- Share feedback through GitHub issues  
- Submit pull requests with updates  

⚠️ Please note:  
- All contributions will also be licensed under CC BY-NC 4.0  
- Respect trademarks and attribution requirements  
- Keep contributions professional and constructive
